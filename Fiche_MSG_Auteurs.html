Fayol (Henry)

Industriel issu grande école, fin XIXe. 1er auteur à présenter des fonctions de l'organisation. Crée la fonction administration (= aujourd'hui : fonction de management). 5 fonctions de l'administration / manager :

  • 1. Prévoir : envisager l'avenir et dresser programme d'actions → GEPC, budget prévisionnel
  • 2. Organiser : définir de façon claire les responsabilités de chacun → organigramme préconisé
  • 3. Coordonner : mettre de l'« harmonie » entre les acteurs → recommander de mettre en place des contacts (réunions). Mécanismes de coordination (Mintzberg) : standardisation (formelle), supervision directe, ajustement mutuel
  • 4. Commander / Diriger (avant : commander, mtn : diriger) : nécessite bcp de qualités humaines (softskills) pour faire adhérer les acteurs = fidéliser maintenant
  • 5. Contrôler : fondamental → superviser / vérifier que les ordres sont bien faits / respectés. Tâche la plus importante avec les softskills → d'où le tableau de bord

« Harmonie » = bon climat social (perçue par Taylor bien avant Fayol).

Marketing, Mercatique, Communication & Notoriété NOUVEAU — Mana Exo 1À VÉRIFIER : Liminaire / D? — Reorder vague 1

Marketing / Mercatique — formulation exacte

Le marketing = « ensemble de techniques (de gestion) et d'actions ayant pour objectif d'étudier et d'influencer les besoins et les comportements des consommateurs afin de réaliser en continu les adaptations de la production et de l'appareil commerciale en fonction des besoins précédemment cités ».

  • Techniques = moyens de faire
  • Actions = étude des B et comportements consommateurs (service marketing → comportement d'achat → service commercial)
  • OBJECTIF / BUT : satisfaction client
  • S. marketing = théorie / S. prod + commercial = opérationnel
Marketing direct — formulation exacte

« Technique de communication personnalisée et individualisée ayant pour objet de répondre + ou − immédiatement aux besoins du client ».

  • Personnalisée → adapter par sous-groupes
  • Individualisée → séparer les groupes (1 client = 1 message)
Plan de marchéage (Kotler — 4P)

Le plan de marchéage = 4P de Kotler : Produits (caractéristiques ?) · Prix (combien ?) · Communication (média ?) · Distribution.

Publicité — formulation exacte

« Technique de communication dont l'objectif est de modifier l'attitude et/ou le comportement des consommateurs à l'égard d'un produit ».

Méthode — Plan de Communication (5 étapes)

Plan de communication = programmation / étude de comment faire.

  1. Identifier la cible (1 cible = 1 plan de comm ; 4 cibles = 4 plans). Chacun à ses ressentis.
  2. Définir des objectifs :
    • Cognitif = informer
    • Affectif = créer du lien
    • Conatif = susciter l'achat (l'achat, racheter…)
  3. Déterminer le message (objectifs ≠ → messages ≠) — message déterminé avec étape du dessus
  4. Canaux :
    • Média : TV, Radio, Presse, Affichage, Cinéma, Internet
    • Hors média : pub sur lieu de vente (dégustation…), sponsoring (affect), bouche à oreille (com par client). Ex : artisanat, [Iddle], agence immobilière → 2 commerce que comme ça
  5. Support :
    • Pub TV → spot pub
    • Radio → spot audio (ex Leclerc : insérer vie particulière de promo, long moment évolution de la vie)
    • Presse → encart publicitaire (achat d'espace = achat d'encart)
    • Affiche → affiche lumineuse

    Note : médias à la base hors digitaux. Maintenant tout en digital. Radio → podcast. Presse → journaux Michel. Affichage → affiche digitale. Cinéma → home cinéma à la maison.

Télé-marketing (= phoning) — formulation exacte

« Définit comme techniques de marketing direct utilisant le téléphone pour communiquer avec les prospects et les clients ».

Limites du démarchage aujourd'hui :

  1. les gens utilisent les téléphones portables → possibilité de mettre en spam
  2. raison légale : RGPD → on ne peut ø vendre les données sans le consentement des clients → entreprises ne peuvent plus vendre de données
  3. raison légale : réglementation sur la vie privée
Relations publiques (avant 2011) — formulation exacte

« Regroupe l'ensemble des techniques et des actions permettant de gérer la réputation et l'image d'une entreprise, d'une marque auprès des différents publics ».

Image de marque — formulation exacte

« Perception du consommateur sur la marque / l'entreprise ».

Communication institutionnelle

« A pour objet de réaliser des relations publiques » → objectif affectif ou cognitif → Plan de communication.

Notoriété d'une marque — formulation exacte

« Le fait pour une entreprise ou marque d'être connue par les consommateurs ».

  • Notoriété positive : ex Restos du ❤
  • Notoriété négative : ex Shein, Total, Michelin

Distinction CRUCIALE Entreprise vs Marque :

  • Entreprise = enseigne = statut juridique
  • Marque = visible pour le client
  • Ex : Peugeot (marque) ; Stellantis (entreprise). Zara (marque) ; Inditex (entreprise)
  • Ex : Facebook (entreprise) → rachat Twitter / absorption Instagram → après rachat ø entreprise → devient marque
3 indicateurs — Mesure de la notoriété
  1. Notoriété spontanée : marque qui vient au client sans aide (ex : « quelles marques de X connaissez-vous ? »)
  2. Notoriété assistée : on donne des choix au client, il dit ce qu'il connaît dedans
  3. Notoriété Top of Mind : « notoriété de premier rang → compter le nombre de fois où une entreprise est citée en 1er en notoriété spontanée (cité le + de fois) → 1 dans chaque étude de notoriété spontanée »
Données / Information client

Données = data : R. Intangible. Technologique / Mercatique. « Or noir des entreprises » → qqch de valorisable car exploitable et rapportable. Sans data ø d'info clients.

Management, RH, SI & Information AJOUTÉ

Définitions à connaître
Définition — Management

Processus par lequel les résultats sont obtenus de façon efficace et efficiente via et avec la coopération d'autrui.

Définition — Efficience

Effectuer une tâche correctement, maîtrise de la relation entre les ressources et le rendement, en cherchant à minimiser le coût du processus.

Définition — Efficacité

Mesure se référant au fait d'effectuer les tâches qui s'imposent, d'atteindre les objectifs.

Définition — Contrôle (Yates, 1989)

Ensemble de moyens mis en œuvre pour s'assurer de l'atteinte des objectifs fixés.

Définition — GRH

Aptitude de l'entreprise à assurer l'adéquation entre ses moyens humains et l'évolution constante de ses besoins en compétences dans l'optique d'assurer sa pérennité.

Définition — Information

Renseignement, connaissance dont les fonctions principales sont la réduction de l'incertitude lors de la prise de décision, la réalisation de tâches et la communication.

Définition — Source d'information

Une source d'information se définit comme d'où vient l'information. Peut être externe/interne, primaire/secondaire.

Définition — SI (Reix)

Ensemble organisé de ressources (matériel, logiciel, personnel, données, procédures) permettant d'acquérir, traiter, stocker, communiquer des informations dans des organisations.

Définition — Collecte de données

Approche systématique consistant à réunir et mesurer des informations en provenance de sources variées, afin d'obtenir une vue complète et précise d'un domaine d'intérêt.

Définition — Machine Learning

Ensemble de techniques donnant aux machines la capacité d'apprendre automatiquement un ensemble de règles à partir de données. Contrairement à la programmation (exécution de règles prédéterminées).

Yates (1989)

Contrôle = moyens mis en œuvre pour assurer l'atteinte des objectifs.

Reix

SI = ensemble organisé de ressources pour acquérir, traiter, stocker, communiquer des informations.

Système comptable & PCG NOUVEAU — Mana Exo 2

PCG — Plan Comptable Général

Le PCG va enregistrer les flux qui ø jour après jour dans une certaine chose (en €) par l'entreprise vis à vis de ses parties prenantes.

Le PCG classifie les comptes en classes (= catégories), crée 8 grandes catégories de comptes.

Écriture comptable

Une écriture comptable = traduction comptable des échanges (flux).

3 types de flux :

  • Monétaire (= paiement) → physique / réel
  • Financier (= investissement)
  • Informationnel

En compta : mouvement = flux / mod. Débit (gauche) / Crédit (droite).

Règle de la partie double : tjrs deux flux. Le journal a un libellé qui explique la transaction et permet la traçabilité.

Enregistrement (VOC)

Un enregistrement = reconnaissance des relations entre l'entreprise et ses parties prenantes.

Les classes du PCG

ClasseNomContenu
1Comptes capitauxTraduction de la dette d'une organisation aux regards des parties prenantes (actionnaires…). Flux financier.
2Comptes d'immobilisationActifs détenus par l'entreprise pendant longtemps : actif incorporel (intangible), actif corporel (tangible), actif financier (actions / obligations). Investissement ≠ charges.
3Comptes de stock et en coursMarchandises (à revendre en l'état), Matières premières, Produits finis, Produits encours, Industriel transformation. Compte de stocks consolidé.
4Comptes de tiersComptes de Pres / classe 6/7 mélanger. Tiers = parties prenantes / acteurs qui ont des relations avec l'organisation (externes : collab, salariés, État, clients, fournisseurs). Dû au décalage dans le temps.
5Comptes financiersBanque (5/12) : encaissements / décaissements. Ce compte doit toujours être positif (toute l'argent convoité obtenu).
6Comptes de chargesEnsemble des charges. Charges ≠ coûts. Mat. 1ère / personnel… Doivent être amorties → amortissement = perte de valeur des immobilisations.
7Comptes de produitsProduits financiers, produits clés, ventes de biens, toutes les ventes qui rapportent de l'argent.

5ème classe → BILAN | 6 et 7 → Compte de Résultats

  • Bilan : reflète le patrimoine de l'entreprise
  • Compte de Résultats = comptes de gestion
  • Logique comptable : Journal → comptes ent° → PCG
Résultat (R)

R = Produits − Charges = (7) − (6)

  • R > 0 → bénéfice
  • R < 0 → perte
  • R = 0 → nul
Inventaire
  • Inventaire intermittent : 1 fois par an → compter tt les biens
  • Inventaire permanent : tous les jours, à chaque achat déduction sur stock → pousse ø de rupture de stock. Dresser au moment de clôture (= fin année comptable) → permet de dresser la valeur du patrimoine.

Comptabilité analytique : coûts complets. Optimiser le stock (le stockage coûte).

Créances / Dettes / Paiement
  • Créances = ressources
  • Dettes = dépenses
  • Payer = décaisser, vendre = encaisser

2 types de paiement :

  • Paiement au comptant
  • Paiement à crédit (= acheter / vendre demande confiance) → attendre paiement → écart / décalage de trésorerie (35-40j) → besoins de financement → délai d'avoir
Image fidèle / Audit

Compta rôle de l'audit → SARRs (par analyse) → contrôle (parties prenantes) → sur plusieurs périodes (notion type) → rendu.

Image fidèle : la compta doit donner une image fidèle de l'organisation. Si on se trompe → contrepassation (annule les écritures de vérification, on annule les écritures).

Règle : « tout ce qui se passe doit être enregistré ».

⚠️

Erreurs / Pièges : ø de calcul, ou annule par contrepassation si on se trompe. Le compte 5 (banque) doit toujours être positif. Investissement ≠ charges (l'investissement va générer des fruits dans plusieurs périodes, pas dans une seule).
